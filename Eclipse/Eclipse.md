# Конспект: Примитивные типы данных в Java

## Введение
В Java примитивные типы данных делятся на **4 категории**:
1. Целочисленные
2. Числа с плавающей точкой
3. Логический тип
4. Символьный тип

Всего в Java **8 примитивных типов**: `byte`, `short`, `int`, `long`, `float`, `double`, `boolean`, `char`.

---

## 1. Целочисленные типы

| Тип | Размер | Диапазон | Особенности |
|---|---:|---|---|
| `byte` | 8 бит / 1 байт | от `-128` до `127` | При выходе за диапазон — ошибка компиляции |
| `short` | 16 бит / 2 байта | от `-32 768` до `32 767` | Большие значения не помещаются |
| `int` | 32 бита | от `-2 147 483 648` до `2 147 483 647` | Обычно используется по умолчанию для целых чисел |
| `long` | 64 бита | примерно от `-9.22e18` до `9.22e18` | Нужен суффикс `L` или `l` |

### Примеры
```java
byte b = -128;      // ok
byte b2 = 128;      // ошибка: вне диапазона byte

short s = 20_000;   // ok
short s2 = 200_000; // ошибка: вне диапазона short

int i = 2_000_000_000;      // ok
int i2 = 20_000_000_000;    // ошибка: слишком большое число, нужен long

long l = 9_000_000_000L;    // ok, суффикс L обязателен
long l2 = 9_000_000_000l;   // тоже можно с маленькой l
```

---

## 2. Числа с плавающей точкой

| Тип | Размер | Примерный диапазон | Особенности |
|---|---:|---|---|
| `float` | 32 бита | примерно `±3.4e38`, минимальное положительное ~`1.4e-45` | Нужен суффикс `F` или `f` |
| `double` | 64 бита | примерно `±1.8e308`, минимальное положительное ~`4.9e-324` | Тип по умолчанию для дробных чисел |

### Примеры
```java
float f = 1.01F;     // ok, суффикс F обязателен
// float f2 = 1.01;  // ошибка: 1.01 по умолчанию double

double d = 1.01;     // ok
double d2 = 1.7e308; // ok, E-нотация
double d3 = 5e-50;   // ok
```

### E-нотация
Запись вида `1.7e308` означает:
```text
1.7 × 10^308
```

А `9e-50` означает:
```text
9 × 10^-50
```

---

## 3. Логический тип `boolean`

- Принимает только два значения:
  - `true`
  - `false`
- Используется для логических условий.
- В видео говорится о «2 битах», но в спецификации Java размер `boolean` строго не определён и зависит от JVM.

### Пример
```java
boolean b = true;
System.out.println(b); // true
```

---

## 4. Символьный тип `char`

- Хранит один символ Unicode.
- Размер: **16 бит**.
- Значение записывается в **одинарных кавычках**.

### Пример
```java
char c = 'ж';
System.out.println(c); // ж
```

---

## Итоговая схема

```text
Примитивные типы Java:
├── Целочисленные:
│   ├── byte   (8 бит)
│   ├── short  (16 бит)
│   ├── int    (32 бита)
│   └── long   (64 бита, суффикс L)
├── С плавающей точкой:
│   ├── float  (32 бита, суффикс F)
│   └── double (64 бита, по умолчанию)
├── Логический:
│   └── boolean (true / false)
└── Символьный:
    └── char (16 бит, Unicode)
```

## Главное запомнить
- У каждого типа есть свой диапазон значений.
- Выход за диапазон — ошибка компиляции.
- Для `long` нужен суффикс `L`.
- Для `float` нужен суффикс `F`.
- Дробные числа по умолчанию имеют тип `double`.
- `boolean` хранит `true` или `false`.
- `char` хранит один символ Unicode.
